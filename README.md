# Postrinch

An agent-first desktop mail client, written in Rust on [rinch](https://github.com/joeleaver/rinch).

Every account you have, in one place, kept on your own machine, with search that understands what you mean. Everything you can do in the window, an agent can do too, through MCP.

> *postrinner* (Older Scots): one who travels post-haste; a fast courier.

**Status:** design. Nothing is built yet. Start with [DESIGN.md](DESIGN.md).
